GTA 6 PC scams: two fake GitHub ports flagged by Bitdefender researchers

Clubic and KultureGeek report two fake Windows projects that used an administrator command to launch malicious code.

图片：Rockstar Games

来源 clubic.com · kulturegeek.fr

Two GitHub repositories advertising GTA 6 for Windows led users into a malicious installation chain, Clubic reports, citing Bitdefender researchers. The crucial step was an instruction to run a command with administrator privileges. According to the report, GitHub removed both pages after the researchers flagged them.

What did the fake PC ports promise?

One repository advertised a complete cracked game without an additional launcher. The other presented itself as a community effort to run the console release on Windows. KultureGeek describes detailed hardware requirements alongside promises of improved graphics, high frame rates, mods and online play without a Rockstar account. The packaging made the pages resemble plausible installation documentation.

The shared mechanism was more consequential than the promises. Users were told to open Windows Terminal or PowerShell with elevated privileges and paste a supplied command. Clubic says that command downloaded a remote script and immediately ran it. This report does not reproduce the command or the distribution address.

Why does the installation method matter?

Both reports describe a ClickFix approach, in which people are persuaded to execute the attacker’s code themselves under an installation or troubleshooting pretext. KultureGeek notes that one page even suggested adding a Windows Security exclusion if the download failed. Assertions about open source code or clean antivirus results did not establish what the remote installation chain would actually do.

The reports describe the final payload with slightly different levels of certainty. Clubic calls information theft the very likely objective and notes that the distributed malware can change. KultureGeek describes an information stealer. That evidence concerns the two reported repositories; it does not establish that every unofficial technical project has the same purpose or payload.

Why it matters

Demonstrations of unofficial ports and malicious pages copying their language are separate things. A video showing experimental progress does not authenticate an installer elsewhere, and a GitHub address does not make a release official. Our release guide keeps the announced platforms separate from community experiments and unsupported promises.

For anyone who ran the supplied command, Clubic relays Bitdefender’s advice to disconnect the computer, perform a full security scan and change passwords from a clean device. It also recommends revoking active sessions and checking accounts. Those are the researchers’ response recommendations for the reported campaign, rather than a diagnosis of an individual reader’s machine or evidence that a closed terminal window means nothing happened.
