GTA 6 PC 诈骗：Bitdefender 研究人员标记的两个假 GitHub 端口

Clubic 和 KultureGeek 报告了两个假冒 Windows 项目，这些项目使用管理员命令来启动恶意代码。

来源 clubic.com · kulturegeek.fr

Clubic援引 Bitdefender 研究人员的话说，两个宣传 Windows 版GTA 6的 GitHub 存储库导致用户进入恶意安装链。关键的一步是指示以管理员权限运行命令。据报道，在研究人员标记后，GitHub 删除了这两个页面。

假冒的 PC 端口承诺了什么？

一个存储库宣传了一款完整的破解游戏，没有额外的启动器。另一个则是社区努力在 Windows 上运行控制台版本。 KultureGeek描述了详细的硬件要求，并承诺提供改进的图形、高帧速率、模组和无需Rockstar帐户的在线游戏。包装使页面类似于看似合理的安装文档。

共享机制比承诺更重要。用户被告知以提升的权限打开 Windows 终端或 PowerShell 并粘贴提供的命令。 Clubic 表示该命令下载了远程脚本并立即运行它。本报告不会重现该命令或分发地址。

为什么安装方法很重要？

这两份报告都描述了 ClickFix 方法，在这种方法中，人们被说服以安装或故障排除为借口自行执行攻击者的代码。 KultureGeek 指出，有一个页面甚至建议在下载失败时添加 Windows 安全排除项。关于开源代码或干净的防病毒结果的断言并没有确定远程安装链实际上会做什么。

延伸阅读 AMD BC-250 上的GTA 6 FPS 截图不是PS5基准

这些报告对最终有效载荷的描述程度略有不同。 Clubic 将信息盗窃称为很可能的目标，并指出分布式恶意软件可能会发生变化。 KultureGeek 描述了一种信息窃取者。该证据涉及两个报告的存储库；它并没有规定每个非官方技术项目都具有相同的目的或有效负载。

为什么这很重要

非官方端口的演示和复制其语言的恶意页面是不同的事情。显示实验进度的视频不会验证其他地方的安装程序，GitHub 地址也不会正式发布。我们的发布指南将已宣布的平台与社区实验和不受支持的承诺分开。

对于任何运行所提供命令的人，Clubic 都会转达 Bitdefender 的建议，即断开计算机连接、执行全面的安全扫描并从干净的设备更改密码。它还建议撤销活动会话和支票账户。这些是研究人员对所报告的活动的响应建议，而不是对单个读者机器的诊断或关闭终端窗口意味着什么都没有发生的证据。
