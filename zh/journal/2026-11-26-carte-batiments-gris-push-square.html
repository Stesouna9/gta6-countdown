Push Square表示， GTA 6地图颜色：可以进入深灰色建筑物

Push Square 描述了无障碍建筑物的地图颜色提示，以基伦托 (Key Lento) 的邻近房屋进行说明。

来源 pushsquare.com

Push Square强调了GTA 6地图的细节，可以让探索变得更容易：在它描述的示例中，可以进入深灰色的建筑物，而不能进入浅灰色的建筑物。该报告使用 Key Lento 的邻近房屋展示了差异。这是一个很小的视觉提示，但可以帮助玩家决定哪些门值得接近。

记者注意到了什么？

Push Square 的作者描述了尝试建造一栋外面有花园侏儒的房子，但却找不到进去的路。看地图，发现有两种灰色阴影。邻近的住宅显得较暗，记者得以进入。这种比较构成了提示的基础，而不是Rockstar关于新功能的公告。

玩家可以在绕着建筑物寻找入口之前检查建筑物的颜色来测试观察结果。我们尚未对Leonida每一处房产进行调查，因此该报告不应无一例外地作为独立验证的规则呈现。它的价值在于它提供了一个清晰、具体的线索，可以在普通探索过程中进行检查。

入口并不是完成目标

地图颜色告诉我们的信息也是有限的。 Push Square 的例子涉及是否可以进入建筑物。它并没有规定每个可进入的内部空间都包含收藏品、任务或奖励。将这些不同的问题视为可互换的，会将有用的导航提示变成比证据支持的更广泛的主张。

这种区别为漫游留下了空间，而无需将每次访问都列为清单的一部分。玩家可以使用阴影来选择绕道，然后在到达时发现里面有什么。我们的社区页面提供了讨论这些发现的地方，同时让其他人在自己探索之前决定他们想要透露多少内容。

为什么这很重要

实际的变化在于玩家阅读屏幕上已有信息的方式。 Push Square 的报告中没有任何内容表明补丁在一夜之间增加了颜色区分。相反，这篇文章引起了人们对记者之前忽视的一个特征的关注。在确定房屋只是风景之前，检查地图上的阴影现在是一个具体的尝试步骤。仍然需要更广泛的测试或官方解释来确定整个游戏世界观察的全部限制。
