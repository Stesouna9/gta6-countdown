GTA 6 ：GitHub 的 X 帐户删除了有关盗版端口的帖子

据 Frandroid 援引 Kotaku 报道，11 月 26 日至 27 日晚，GitHub 的 X 账户赞扬了 Any PS5工具并提到盗版GTA 6移植，然后删除了该消息。

来源 frandroid.com

微软子公司 GitHub 的官方 X 账户发布了一条庆祝盗版GTA 6移植的消息，然后又删除了。 Frandroid援引 Kotaku 的话讲述了这个故事。

GitHub 的消息说了什么？

11 月 26 日至 27 日晚，GitHub 推广了 Any PS5 ，该项目将PS5游戏转换为 PC 可执行文件。该帖子公开提及盗版GTA 6端口，并祝其社区“ GTA 6圣诞快乐”。根据 Frandroid 的说法，随附的视频询问“改变游戏的运行方式是否真的合法”，并详细介绍了 Any PS5 ，其性能似乎是“最大的限制之一”。几小时后，该帖子被删除。

背景： Rockstar与港口

Take-Two于周二删除了 3,007 个 GitHub 存储库，这是我们整个星期都在关注的一波删除浪潮，而且CGBJ 存储库现在无法访问。 Frandroid 指出，GitHub 的消息仍然强调，该游戏的发布恰逢其平台上“开源和游戏活动最活跃的一周之一”。

该媒体还回忆道，在发布前几周，Strauss Zelnick对这些端口的态度很平静：“几乎每个人都想以Rockstar想象的方式体验Rockstar ”。

延伸阅读 据 01net 报道， GTA 6 PC 60 FPS 声称涉及过场动画

我们不知道什么

据 Frandroid 报道，GitHub 和微软都没有对此次删除做出解释。目前尚不清楚这是一个失误还是一个节制决定， Rockstar尚未在我们读到的消息来源中做出回应。实质上，该版本仍仅限于PS5和Xbox Series X|S ：未公布 PC 版本。

为什么这很重要

对玩家没有直接影响。不过，这一集显示，托管这些端口的平台并应Take-Two的要求删除了数千个存储库，同时还发布了庆祝它们的内容。到目前为止，这一明显的矛盾尚未得到评论。
