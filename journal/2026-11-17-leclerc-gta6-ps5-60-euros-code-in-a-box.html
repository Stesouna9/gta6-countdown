GTA 6 PS5 à 60 € chez E.Leclerc : une boîte avec code, sans disque

Selon Le Figaro, E.Leclerc propose GTA 6 sur PS5 à 60 euros en « Code in a Box », sans disque, avec retrait en deux heures dans 94 magasins.

Sources lefigaro.fr

J-1 GTA 6 sort dans 1 jours →

E.Leclerc remet GTA 6 en stock sur PS5 à 60 euros, rapporte Le Figaro dans sa rubrique bons plans. Le tarif est inférieur aux 79,99 € de l'édition standard sur le PlayStation Store.

Que contient la boîte E.Leclerc à 60 € ?

Il s'agit d'une version « Code in a Box » : malgré le mot « boîte », aucun disque n'est fourni, seulement un code d'activation numérique, précise Le Figaro. Les précommandes reçoivent aussi le pack Vintage Vice City, présenté comme un bonus. Le code permet de précharger le jeu pour être prêt le 19 novembre.

Où et comment le retirer ?

Le Click & Collect est gratuit, avec un retrait possible en deux heures dans 94 magasins qui proposent l'offre. Attention : le code ne fonctionne qu'avec un compte PlayStation enregistré en France ou dans une liste restreinte de pays européens, ce qui exclut un achat pour un compte d'une autre région.

Faut-il se méfier des boîtes avec code ?

La rubrique du Figaro est rédigée par son équipe Shopping, indépendante de la rédaction, et peut toucher une commission d'affiliation : le prix est indicatif. Sur le terrain, nous avons déjà relevé des boîtes sans code signalées et des faux sites de précommande : achetez en magasin ou chez un revendeur connu, et vérifiez le code avant de l'utiliser. Tous les tarifs officiels sont sur la page prix.

Ce que ça change

Pour qui n'a pas encore acheté, 60 € vaut près de 20 € de moins que le prix public numérique, à condition de trouver du stock. Le Figaro ne dit pas jusqu'à quand l'offre court, et rien ne dit qu'une offre équivalente existe sur Xbox.
