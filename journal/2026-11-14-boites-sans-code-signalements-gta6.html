GTA 6 : des boîtes livrées sans code signalées sur PS5 et Xbox

Notebookcheck rapporte des boîtes scellées sans code sur PS5 et Xbox, avec des demandes d’aide restées sans solution dans les cas cités.

Sources notebookcheck.net

Selon Notebookcheck, certains acheteurs de GTA 6 ont reçu une boîte scellée sans code de téléchargement utilisable. Le média cite des cas sur PlayStation et Xbox, ainsi que des démarches auprès de vendeurs et de Rockstar restées sans solution pour les clients concernés. Il ne fournit pas de chiffre permettant de mesurer l’ampleur du problème.

Que manque-t-il dans les boîtes signalées ?

Notebookcheck décrit notamment un acheteur PS5 dont l’encart intérieur présente une bande grise à la place du code attendu. Un autre témoignage, attribué au membre Reddit InParties, concerne une commande passée directement auprès de Rockstar : le poster serait présent, mais pas le code PlayStation Store. Ces récits restent des signalements rapportés par la presse, pas un bilan établi par le fabricant.

Le point est concret : dans une édition livrée sous forme de code en boîte, posséder le boîtier ne suffit pas à débloquer le jeu. L’absence de code empêche la récupération de l’achat numérique. Le poster ne remplace évidemment pas cet accès, même si les autres éléments du paquet semblent présents.

Quelle réponse les acheteurs ont-ils obtenue ?

D’après Notebookcheck, Best Buy a refusé un remboursement dans l’un des cas cités. Le client ayant commandé chez Rockstar aurait vu deux tickets d’assistance fermés. Cela décrit le parcours de ces personnes ; cela ne prouve ni une politique générale de refus ni le traitement réservé à tous les dossiers.

À lire aussi GTA 6 sur PS5 : un risque de vol des codes en boîte signalé par la presse

Notebookcheck indique également que le site de Rockstar renvoie vers le revendeur pour les achats effectués auprès d’un tiers. Le média envisage une erreur de fabrication, mais cette explication n’est pas confirmée. Aucun rappel de lot ni décompte officiel des boîtes concernées n’est donné dans le texte consulté.

Ce que ça change

Ces signalements ajoutent un problème différent au risque de lecture des codes à travers certaines boîtes déjà évoqué par la presse. Un code manquant et un code volé ne sont pas interchangeables : aucune preuve ne permet ici d’attribuer tous les cas à une même cause.

Pour préparer la sortie du 19 novembre, la distinction utile est celle entre livraison du produit et accès effectif au jeu. Les témoignages invitent à conserver les éléments de commande et à décrire précisément le contenu reçu au vendeur. Ils ne permettent pas d’annoncer un défaut généralisé des éditions PS5 ou Xbox, ni de promettre un remboursement ou un remplacement automatique.
