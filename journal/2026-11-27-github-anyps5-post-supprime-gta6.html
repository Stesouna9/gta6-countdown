GTA 6 : le compte X de GitHub supprime un post sur les portages pirates

Dans la nuit du 26 au 27 novembre, le compte X de GitHub a vanté l'outil AnyPS5 et évoqué des portages pirates de GTA 6, avant de supprimer le message, selon Frandroid citant Kotaku.

Sources frandroid.com

Le compte X officiel de GitHub, filiale de Microsoft, a publié puis effacé un message qui célébrait les portages pirates de GTA 6. Frandroid, qui cite Kotaku, raconte l'épisode.

Que disait le message de GitHub ?

Dans la nuit du 26 au 27 novembre, GitHub a fait la promotion d'AnyPS5, un projet qui permet de transformer un jeu PS5 en exécutable PC. Le message mentionnait ouvertement des portages pirates de GTA 6 et souhaitait à la communauté un « Joyeux Noël GTA 6 ». Une vidéo jointe se demandait si « c'est vraiment légal de changer les modalités de fonctionnement d'un jeu » et détaillait AnyPS5, dont les performances semblaient « une des plus importantes limitations », selon Frandroid. Le post a été supprimé quelques heures plus tard.

Le contexte : Rockstar contre les portages

Take-Two a fait fermer 3 007 dépôts GitHub mardi, dans une vague de retraits que nous suivons depuis le début de la semaine, et le dépôt de CGBJ est aujourd'hui inaccessible. Frandroid relève que GitHub soulignait pourtant dans son message que la sortie du jeu avait coïncidé avec « l'une des plus grosses semaines d'activité dans l'open source et dans le gaming » sur sa plateforme.

Le média rappelle aussi que, quelques semaines avant la sortie, Strauss Zelnick affichait sa sérénité face à ces portages : « quasiment tout le monde souhaite vivre l'expérience Rockstar telle que l'a imaginée Rockstar ».

Ce qu'on ne sait pas

Ni GitHub ni Microsoft n'ont, d'après Frandroid, expliqué la suppression du message. On ignore s'il s'agit d'une maladresse ou d'une décision de modération, et Rockstar n'a pas réagi dans les sources que nous avons consultées. Sur le fond, la sortie du jeu reste limitée à PS5 et Xbox Series X|S : aucune version PC n'est annoncée.

Ce que ça change

Pas de conséquence directe pour les joueurs. L'épisode montre toutefois que la plateforme qui héberge les portages, et qui retire des milliers de dépôts à la demande de Take-Two, publie en même temps des contenus qui les valorisent. Cette contradiction apparente n'est pas commentée à ce stade.
