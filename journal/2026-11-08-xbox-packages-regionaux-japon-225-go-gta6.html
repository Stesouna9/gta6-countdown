GTA 6 sur Xbox : environ 225 Go et un package japonais plus léger

Xboxygen rapporte des packages de 225,34 Go et 224,14 Go au Japon dans le catalogue Microsoft. Cet écart ne prouve pas une censure.

Sources xboxygen.com

GTA 6 ne présente pas exactement le même poids dans toutes les régions sur Xbox. Selon Xboxygen, les packages référencés dans le catalogue de Microsoft représentent environ 225,34 Go pour la version mondiale et 224,14 Go pour la version japonaise. Ce sont des données de distribution rapportées par le média, pas une annonce de Rockstar sur le contenu de ces versions.

Pourquoi voit-on à la fois 209,86 et 225,34 ?

Xboxygen s'appuie sur un relevé de Cokymoky dans le DisplayCatalog API de Microsoft. Pour la version mondiale, le média rapproche les valeurs 209,86 Gio et 225,34 Go. Elles décrivent sensiblement la même quantité de données avec deux unités différentes : le gigaoctet décimal et le gibioctet binaire. Le nombre le plus petit ne désigne donc pas nécessairement un téléchargement compressé.

Nous avions déjà expliqué cette distinction dans notre article sur les 209,86 Gio signalés sur Xbox. Le nouvel élément est ici la comparaison des packages régionaux. Pour préparer son stockage, il faut surtout regarder l'espace libre indiqué par sa propre console, puis la taille affichée au moment du téléchargement.

Une version japonaise plus légère, sans explication confirmée

Selon Xboxygen, le package japonais représente environ 208,74 Gio, soit 224,14 Go. L'écart avec la version mondiale est donc de l'ordre de 1,2 Go. Le média signale également des packages australien et néo-zélandais presque identiques à celui du reste du monde. Ces différences décrivent des fichiers distribués ; elles ne disent pas, seules, quelles scènes ou quelles fonctions contiennent ces fichiers.

Xboxygen évoque plusieurs explications possibles, notamment des langues ou des éléments audio régionaux. Aucune n'est établie. La classification japonaise CERO Z déjà rapportée ne permet pas davantage de conclure à une censure. Il faudrait une comparaison documentée ou une précision officielle pour l'affirmer.

Ce que ça change

Pour les joueurs européens sur Xbox Series X|S, l'ordre de grandeur utile est désormais d'environ 225 Go selon les données rapportées par Xboxygen. Ce chiffre ne constitue pas une réserve garantie pour toutes les mises à jour futures. Il ne faut pas non plus additionner les tailles régionales : on n'installe pas tous ces packages pour jouer à une seule version.

Le rendez-vous reste le 19 novembre sur PS5 et Xbox Series X|S. Notre page consacrée à la sortie rassemble les repères pratiques. Ici, la nouveauté porte sur la distribution Xbox et ses variantes régionales, sans preuve d'une différence de contenu jouable.
