GTA 6 : tous les codes de triche, la liste et comment les débloquer

GTA 6 compte 61 triches, à débloquer en jouant puis à saisir à la croix directionnelle. 17 codes sont déjà confirmés par deux guides.

Sources powerpyx.com · gtabase.com

Les triches sont bien là : GTA 6 en compte 61, réparties en cinq familles (joueur, combat, véhicules, environnement, filtres d'écran). Nouveauté par rapport à GTA 5 : chaque triche se débloque d'abord en jouant (finir l'histoire, médailles aux stands de tir, défis…), puis se saisit à la croix directionnelle. Liste relevée sur PowerPyx, GTABase, sans spoiler d'histoire.

Quels codes de triche de GTA 6 sont confirmés ?

Ces 17 combinaisons apparaissent à l'identique dans les deux guides :

  • $250,000 : vous donne instantanément 250 000 $. Code : UP > RIGHT > DOWN > LEFT > UP > LEFT > DOWN > RIGHT. Déblocage : Terminez l'histoire.
  • Raise Heat Level : Augmente votre niveau de chaleur sur la carte. Code : LEFT > DOWN > RIGHT > DOWN > UP > DOWN > UP. Déblocage : Perdez un niveau de recherche 3 étoiles 25 fois..
  • Unlimited Focus : La concentration ne s'épuise jamais. Code : DOWN > UP > UP > DOWN > UP > DOWN > UP > DOWN > UP > RIGHT. Déblocage : Terminez l'histoire.
  • Body Armor : Ajoute un gilet pare-balles à votre équipement. Code : DOWN > UP > LEFT > UP > UP > UP > UP > UP > DOWN > DOWN. Déblocage : Effectuez 100 séances d'entraînement..
  • Max Ammo : Remplit toutes les munitions au maximum. Code : DOWN > UP > RIGHT > DOWN > LEFT > LEFT > UP > UP > DOWN > LEFT. Déblocage : Gagnez 25 médailles de bronze ou plus aux stands de tir..
  • Infinite Ammo : Les munitions ne s'épuisent jamais. Code : DOWN > UP > RIGHT > DOWN > LEFT > LEFT > UP > DOWN > DOWN > DOWN. Déblocage : Gagnez 25 médailles d'argent ou plus aux stands de tir..
  • No Reload : Les munitions ne s'épuisent jamais et il n'est pas nécessaire de recharger. Code : DOWN > UP > RIGHT > DOWN > LEFT > LEFT > UP > DOWN > DOWN > UP. Déblocage : Gagnez 25 médailles d'or aux stands de tir..
  • Attack Force : Les balles et les attaques de mêlée lancent des cibles à l'impact. Code : DOWN > UP > LEFT > LEFT > RIGHT > DOWN > DOWN > UP > DOWN. Déblocage : Terminez l'histoire.
  • Exploding Balls : Les ballons de sport explosent à l'impact. Code : DOWN > UP > LEFT > LEFT > RIGHT > DOWN > DOWN > UP > RIGHT. Déblocage : Frappez 20 ennemis avec des dégâts explosifs.
  • Vehicle Force : Objectifs de lancement des collisions de véhicules. Code : DOWN > UP > LEFT > LEFT > RIGHT > DOWN > LEFT > UP > DOWN. Déblocage : Tuez 25 ennemis avec un véhicule (conduire sur des civils compte aussi).
  • Maibatsu Boomazoom : Génère un Maibatsu Boomazoom. Code : LEFT > UP > RIGHT > DOWN > LEFT > LEFT > UP > LEFT. Déblocage : Terminez 5 défis de magasinage..
  • MTL Pumper : Génère un Pumper MTL. Code : LEFT > UP > RIGHT > DOWN > LEFT > RIGHT > RIGHT > UP. Déblocage : Inconnu.
  • HVY Bulldozer : Fait apparaître un bulldozer HVY. Code : LEFT > UP > RIGHT > DOWN > LEFT > RIGHT > RIGHT > DOWN. Déblocage : Découvrez le HVY Bulldozer dans le menu Progression..
  • Cycle Weather : Modifie la météo, en parcourant les différents types de temps. Code : DOWN > RIGHT > UP > DOWN > RIGHT > UP > RIGHT. Déblocage : Terminez l'histoire.
  • Cataclysm : Remplit le monde d'une fumée trouble. Code : DOWN > DOWN > UP > RIGHT > RIGHT > UP > LEFT > LEFT > RIGHT > RIGHT. Déblocage : Découvrez Martha's Vamos dans le menu Progression.
  • Dollhouse : Applique un filtre vif avec un rapport hauteur/largeur étroit. Code : DOWN > DOWN > UP > RIGHT > RIGHT > UP > LEFT > LEFT > DOWN > RIGHT. Déblocage : Passez 8 heures avec votre partenaire.
  • Faded Glory : Applique un filtre TV CRT couleur. Code : DOWN > DOWN > UP > RIGHT > RIGHT > UP > LEFT > LEFT > LEFT > RIGHT. Déblocage : Volez 50 magasins avec votre partenaire.

Et les autres triches ?

Pour les 44 autres, l'effet et la condition de déblocage sont connus mais la combinaison n'est pas encore recoupée : elles sont marquées « à confirmer » sur notre page des triches de GTA 6, mise à jour toutes les heures.

À lire aussi : les faux codes qui circulaient avant la sortie et la liste des 55 trophées. Attention : selon les deux guides, activer une triche désactive les trophées et la sauvegarde.
