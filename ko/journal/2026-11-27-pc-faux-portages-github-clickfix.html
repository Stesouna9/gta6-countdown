GTA 6 PC 사기: Bitdefender 연구원이 표시한 가짜 GitHub 포트 2개

Clubic과 KultureGeek은 관리자 명령을 사용하여 악성 코드를 실행한 두 개의 가짜 Windows 프로젝트를 보고했습니다.

출처 clubic.com · kulturegeek.fr

Bitdefender 연구원의 말을 인용하여 Windows용 GTA 6 광고하는 두 개의 GitHub 리포지토리가 사용자를 악성 설치 체인으로 유도했다고 Clubic이 보고했습니다. 중요한 단계는 관리자 권한으로 명령을 실행하라는 지시였습니다. 보고서에 따르면 GitHub는 연구원들이 신고한 후 두 페이지를 모두 제거했습니다.

가짜 PC 포트는 무엇을 약속했는가?

한 저장소에서는 추가 런처 없이 완전히 크랙된 게임을 광고했습니다. 다른 하나는 Windows에서 콘솔 릴리스를 실행하려는 커뮤니티의 노력으로 나타났습니다. KultureGeek에서는 향상된 그래픽, 높은 프레임 속도, 모드 및 Rockstar 계정 없이 온라인 플레이를 약속하는 것과 함께 상세한 하드웨어 요구 사항을 설명합니다. 포장으로 인해 페이지가 그럴듯한 설치 문서와 유사해졌습니다.

공유 메커니즘은 약속보다 더 중요했습니다. 사용자에게는 높은 권한으로 Windows 터미널 또는 PowerShell을 열고 제공된 명령을 붙여넣으라는 메시지가 표시되었습니다. Clubic은 해당 명령이 원격 스크립트를 다운로드하고 즉시 실행했다고 말합니다. 이 보고서는 명령이나 배포 주소를 재현하지 않습니다.

설치 방법이 왜 중요합니까?

두 보고서 모두 설치 또는 문제 해결을 구실로 사람들이 공격자의 코드를 직접 실행하도록 설득하는 ClickFix 접근 방식을 설명합니다. KultureGeek에서는 한 페이지에서 다운로드가 실패한 경우 Windows 보안 제외를 추가할 것을 제안하기도 했습니다. 오픈 소스 코드 또는 깨끗한 바이러스 백신 결과에 대한 주장은 원격 설치 체인이 실제로 수행할 작업을 확립하지 못했습니다.

함께 읽기 GTA 6 PC 출시: 209GB 토렌트는 실제 포트가 아니라고 TweakTown은 말합니다.

보고서는 약간 다른 확실성 수준으로 최종 페이로드를 설명합니다. Clubic은 정보 도난을 목적으로 삼을 가능성이 매우 높으며 배포된 악성 코드가 바뀔 수 있다고 지적합니다. KultureGeek은 정보 도둑을 설명합니다. 그 증거는 보고된 두 저장소에 관한 것입니다. 모든 비공식 기술 프로젝트가 동일한 목적이나 페이로드를 가지고 있음을 입증하지는 않습니다.

왜 중요한가요?

비공식 포트의 시연과 해당 언어를 복사하는 악성 페이지는 별개의 것입니다. 실험 진행 상황을 보여주는 비디오는 다른 곳에서는 설치 프로그램을 인증하지 않으며 GitHub 주소는 릴리스를 공식화하지 않습니다. 우리의 릴리스 가이드는 발표된 플랫폼을 커뮤니티 실험 및 지원되지 않는 약속과 별도로 유지합니다.

제공된 명령을 실행한 모든 사람에게 Clubic은 컴퓨터 연결을 끊고 전체 보안 검사를 수행하며 깨끗한 장치에서 비밀번호를 변경하라는 Bitdefender의 조언을 전달합니다. 또한 활성 세션을 취소하고 계정을 확인하는 것이 좋습니다. 이는 개별 독자의 기계에 대한 진단이나 닫힌 터미널 창이 아무 일도 일어나지 않았다는 증거가 아니라 보고된 캠페인에 대한 연구원의 대응 권장 사항입니다.
