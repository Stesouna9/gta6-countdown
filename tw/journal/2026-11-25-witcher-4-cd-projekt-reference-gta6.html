CD Projekt 負責人表示， GTA 6為《巫師 4》樹立了標桿

Pause Hardware 報導稱，Michał Nowakowski 預計《巫師 4》將得到廣泛改進，並以GTA V和GTA VI之間的飛躍作為比較。

來源 pausehardware.com

GTA 6已成為 CD Projekt 投資者討論的參考點。根據Pause Hardware報道，聯合執行長 Michał Nowakowski 相信《巫師 4》能夠實現對《巫師 3》的飛躍，堪比Rockstar兩款最新主線GTA遊戲之間的變化。這是關於波蘭工作室雄心勃勃的聲明，帳戶中並未宣布兩家公司之間存在合作關係。

GTA 6是如何進入討論的？

Pause Hardware 報導，Erste 分析師 Krzysztof Tkocz 在 CD Projekt 第三季業績發布會上提出了這一比較。他的問題是下一個《巫師》能否有類似的進展。諾瓦科夫斯基給出了積極的回答，並指出了自上一場比賽以來的時間。這次交流為標題提供了背景：這是一個關於發展雄心的答案，但沒有公佈這兩個系列的技術排名。

該報告描述了一個目標，包括更好的視覺效果和遊戲幾乎每個部分的改進。這個廣度很重要。更清晰的螢幕截圖可以建立視覺差異；涵蓋整個冒險的聲明邀請玩家考慮在實際玩遊戲時會發生什麼變化。該帳戶沒有指出將展示這種變化的各個機制。

CD Projekt 實際上致力於什麼？

根據 Pause Hardware 報導，Nowakowski 表示團隊已經研究了GTA 6及其與前作的差異。他也表示， Rockstar的發表並沒有改變 CD Projekt 的開發方式。在投資者的回答中使用競爭對手作為例子本身並不能證明產品已經圍繞該競爭對手進行了重新調整。報道的評論支持了雄心壯志的比較，但沒有宣布這種戰略變化。

為什麼這很重要

對於GTA玩家來說，這個消息主要是關於Rockstar的發布現在在業界討論中佔據的地位。對於《巫師 4》來說，這種比較產生了一種超越演示的期望。有用的下一步將是 CD Projekt 的具體範例，展示這項雄心壯志在實踐中意味著什麼。在這些內容到達之前，這些言論提供了一個稍後評估的開發目標，但沒有添加新的GTA功能、 Rockstar公告或證明這兩款遊戲的設計相似的證據。
