GTA 6 PC 詐騙：Bitdefender 研究人員標記的兩個假 GitHub 端口

Clubic 和 KultureGeek 報告了兩個假冒 Windows 項目，這些項目使用管理員命令來啟動惡意程式碼。

來源 clubic.com · kulturegeek.fr

Clubic引述 Bitdefender 研究人員的話說，兩個宣傳 Windows 版GTA 6的 GitHub 儲存庫導致用戶進入惡意安裝鏈。關鍵的一步是指示以管理員權限執行命令。據報道，在研究人員標記後，GitHub 刪除了這兩個頁面。

假冒的 PC 端口承諾了什麼？

一個儲存庫宣傳了一款完整的破解遊戲，沒有額外的啟動器。另一個則是社群努力在 Windows 上執行控制台版本。 KultureGeek描述了詳細的硬體要求，並承諾提供改進的圖形、高幀速率、模組和無需Rockstar帳戶的線上遊戲。包裝使頁面類似於看似合理的安裝文件。

共享機制比承諾更重要。使用者被告知以提升的權限開啟 Windows 終端機或 PowerShell 並貼上提供的命令。 Clubic 表示該命令下載了遠端腳本並立即執行它。本報告不會重現該命令或分發地址。

為什麼安裝方法很重要？

這兩份報告都描述了 ClickFix 方法，在這種方法中，人們被說服以安裝或故障排除為藉口自行執行攻擊者的程式碼。 KultureGeek 指出，有一個頁面甚至建議在下載失敗時添加 Windows 安全排除項目。關於開源程式碼或乾淨的防毒結果的斷言並沒有確定遠端安裝鏈實際上會做什麼。

延伸閱讀 GTA 6 PC: the 180 FPS video looks like frame generation, not a real port

這些報告對最終有效載荷的描述程度略有不同。 Clubic 將資訊竊取稱為很可能的目標，並指出分散式惡意軟體可能會發生變化。 KultureGeek 描述了一種資訊竊取者。該證據涉及兩個報告的儲存庫；它並沒有規定每個非官方技術項目都具有相同的目的或有效負載。

為什麼這很重要

非官方連接埠的演示和複製其語言的惡意頁面是不同的事情。显示实验进度的视频不会验证其他地方的安装程序，GitHub 地址也不会正式发布。我們的發布指南將已宣布的平台與社區實驗和不受支援的承諾分開。

對於任何運行所提供命令的人，Clubic 都會轉達 Bitdefender 的建議，即斷開電腦連接、執行全面的安全掃描並從乾淨的設備更改密碼。它還建議撤銷活動會話和支票帳戶。這些是研究人員對所報告的活動的回應建議，而不是對單一讀者機器的診斷或關閉終端視窗意味著什麼都沒有發生的證據。
