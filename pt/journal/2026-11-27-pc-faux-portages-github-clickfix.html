Golpes GTA 6 para PC: duas portas falsas do GitHub sinalizadas por pesquisadores do Bitdefender

Clubic e KultureGeek relatam dois projetos falsos do Windows que usaram um comando de administrador para lançar código malicioso.

Fontes clubic.com · kulturegeek.fr

Dois repositórios GitHub anunciando GTA 6 para Windows levaram os usuários a uma cadeia de instalação maliciosa, relata Clubic, citando pesquisadores do Bitdefender. A etapa crucial foi uma instrução para executar um comando com privilégios de administrador. De acordo com o relatório, o GitHub removeu ambas as páginas depois que os pesquisadores as sinalizaram.

O que as portas falsas do PC prometeram?

Um repositório anunciava um jogo crackeado completo sem um inicializador adicional. O outro se apresentou como um esforço da comunidade para rodar a versão do console no Windows. KultureGeek descreve requisitos de hardware detalhados juntamente com promessas de gráficos aprimorados, altas taxas de quadros, mods e jogo online sem uma conta Rockstar . A embalagem fazia com que as páginas parecessem uma documentação de instalação plausível.

O mecanismo compartilhado teve mais consequências do que as promessas. Os usuários foram instruídos a abrir o Terminal do Windows ou PowerShell com privilégios elevados e colar um comando fornecido. Clubic diz que esse comando baixou um script remoto e o executou imediatamente. Este relatório não reproduz o comando ou o endereço de distribuição.

Por que o método de instalação é importante?

Ambos os relatórios descrevem uma abordagem ClickFix, na qual as pessoas são persuadidas a executar elas mesmas o código do invasor sob um pretexto de instalação ou solução de problemas. KultureGeek observa que uma página até sugeriu adicionar uma exclusão de segurança do Windows se o download falhar. Afirmações sobre código-fonte aberto ou resultados limpos de antivírus não estabeleceram o que a cadeia de instalação remota realmente faria.

Os relatórios descrevem a carga final com níveis de certeza ligeiramente diferentes. Clubic chama o roubo de informações de objetivo muito provável e observa que o malware distribuído pode mudar. KultureGeek descreve um ladrão de informações. Essas provas dizem respeito aos dois repositórios comunicados; não estabelece que todo projeto técnico não oficial tenha a mesma finalidade ou carga útil.

Por que isso importa

Demonstrações de portas não oficiais e páginas maliciosas que copiam sua linguagem são coisas distintas. Um vídeo mostrando o progresso experimental não autentica um instalador em outro lugar, e um endereço do GitHub não oficializa o lançamento. Nosso guia de lançamento mantém as plataformas anunciadas separadas dos experimentos da comunidade e das promessas não suportadas.

Para qualquer pessoa que executou o comando fornecido, o Clubic transmite o conselho do Bitdefender para desconectar o computador, realizar uma verificação de segurança completa e alterar as senhas de um dispositivo limpo. Também recomenda revogar sessões ativas e contas correntes. Estas são as recomendações de resposta dos investigadores para a campanha relatada, em vez de um diagnóstico da máquina de um leitor individual ou evidência de que uma janela de terminal fechada significa que nada aconteceu.
