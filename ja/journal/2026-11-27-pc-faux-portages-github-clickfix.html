GTA 6 PC 詐欺: Bitdefender 研究者がフラグを立てた 2 つの偽の GitHub ポート

Clubic と KultureGeek は、管理者コマンドを使用して悪意のあるコードを起動した 2 つの偽の Windows プロジェクトを報告しています。

情報源 clubic.com · kulturegeek.fr

Windows 版GTA 6を宣伝する 2 つの GitHub リポジトリがユーザーを悪意のあるインストール チェーンに誘導したとClubic がBitdefender 研究者の話として報じています。重要なステップは、管理者権限でコマンドを実行するための指示でした。報告書によると、研究者が報告した後、GitHub は両方のページを削除しました。

偽の PC ポートは何を約束したのでしょうか?

あるリポジトリは、追加のランチャーなしで完全にクラックされたゲームを宣伝していました。もう 1 つは、Windows 上でコンソール リリースを実行するためのコミュニティの取り組みとして現れました。 KultureGeek では、グラフィックの向上、高フレーム レート、MOD、 Rockstarアカウントなしでのオンライン プレイの約束とともに詳細なハードウェア要件について説明しています。パッケージ化により、ページはもっともらしいインストール ドキュメントに似せられました。

共有メカニズムは約束よりも重要な意味を持ちました。ユーザーは、昇格された特権で Windows ターミナルまたは PowerShell を開き、提供されたコマンドを貼り付けるように指示されました。 Clubic によると、このコマンドはリモート スクリプトをダウンロードし、すぐに実行しました。このレポートでは、コマンドや配布アドレスは再現されません。

インストール方法が重要なのはなぜですか?

どちらのレポートも、インストールやトラブルシューティングを口実として人々を誘導して攻撃者のコードを自分で実行させる ClickFix アプローチについて説明しています。 KultureGeek によれば、あるページでは、ダウンロードが失敗した場合に Windows セキュリティの除外を追加することさえ提案されていました。オープン ソース コードやクリーンなウイルス対策の結果についての主張は、リモート インストール チェーンが実際に何を行うのかを確立していませんでした。

レポートは、わずかに異なるレベルの確実性で最終的なペイロードを説明します。 Clubic は、情報窃盗が目的である可能性が非常に高いと主張し、配布されるマルウェアは変更される可能性があると指摘しています。 KultureGeek は情報窃盗者について説明しています。その証拠は、報告された 2 つのリポジトリに関するものです。すべての非公式技術プロジェクトが同じ目的やペイロードを持っていることを確立するものではありません。

なぜそれが重要なのか

非公式移植のデモンストレーションと、その言語をコピーする悪意のあるページは別のものです。実験の進捗状況を示すビデオは、他の場所でのインストーラーを認証するものではなく、GitHub アドレスは正式なリリースとはなりません。私たちのリリース ガイドでは、発表されたプラットフォームをコミュニティの実験やサポートされていない約束から切り離しています。

Clubic は、提供されたコマンドを実行した人に対して、コンピューターを切断し、完全なセキュリティ スキャンを実行し、クリーンなデバイスからパスワードを変更するよう Bitdefender のアドバイスを伝えます。また、アクティブなセッションと当座預金口座を取り消すことも推奨します。これらは、個々の読者のマシンの診断や、閉じられた端末ウィンドウが何も起こらなかったことを意味するという証拠ではなく、報告されたキャンペーンに対する研究者による推奨対応です。
